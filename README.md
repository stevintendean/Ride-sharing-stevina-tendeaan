#  Ride Sharing DApp
Project ini merupakan aplikasi ride-sharing terdesentralisasi berbasis blockchain Ethereum. 
Aplikasi memungkinkan penumpang (rider) melakukan pemesanan perjalanan dan pengemudi (driver) menerima order secara transparan menggunakan smart contract. 
Sistem pembayaran dikelola melalui smart contract (escrow) agar transaksi aman, adil, dan tidak dapat dimanipulasi.

## 🚀 Fitur Utama
- Registrasi pengemudi (driver) dengan data identitas dan tarif.
- Pemesanan perjalanan oleh penumpang (rider).
- Pemilihan driver secara transparan melalui smart contract.
- Sistem escrow untuk menyimpan pembayaran sampai perjalanan selesai.
- Integrasi Web3 untuk koneksi wallet (MetaMask).
- Tampilan antarmuka web sederhana.
