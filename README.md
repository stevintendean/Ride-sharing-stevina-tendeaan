# Ride-sharing-stevina-tendeaan
aplikasi ride-sharing terdesentralisasi menggunakan teknologi blockchain. Aplikasi ini memungkinkan penumpang (rider) memesan perjalanan dan pengemudi (driver) menerima order secara transparan melalui smart contract berbasis Ethereum. Pembayaran perjalanan harus dikelola melalui smart contract (escrow) agar transaksi aman dan adil
